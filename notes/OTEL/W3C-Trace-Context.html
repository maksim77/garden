    W3C Trace Context

    Заголовок HTTP отвечающий за передачу идентификатора span’а это traceparent. Пример его содержимого:

    traceparent: 00-0af7651916cd43dd8448eb211c80319c-b9c7c989f97918e1-01

    Где через дефис разделены следующие компоненты:

    • version - в настоящий момент всегда 00.
    • trace-id - основной идентификатор трэйса. Следует использовать именно его для поиска в системах типа Jaeger или Zipkin.
    • parent-id - Идентификатор родительского Span’а.
    • trace-flags - служебные флаги

    Source:: https://www.w3.org/TR/trace-context/
